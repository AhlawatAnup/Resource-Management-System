Quick Start

▶
1. Build the image
# From the directory containing your Dockerfile docker build -t ai-datacenter:latest .
▶
2. Run with GPU + mount data
docker run --rm -it \ --gpus all \ -p 8888:8888 \ -v /your/datasets:/data \ -v /your/notebooks:/notebooks \ --name ai-lab ai-datacenter:latest
▶
3. Access Jupyter
Open your browser → http://localhost:8888
Select Python (torch-env) or Python (tf-env) from the kernel picker.
🔥
4. Verify GPU — torch-env
# torch-env kernel import torch print(torch.__version__) # 2.6.0+cu124 print(torch.cuda.is_available()) # True print(torch.cuda.get_device_name(0))
🧠
5. Verify GPU — tf-env
# tf-env kernel import tensorflow as tf print(tf.__version__) # 2.21.0 print(tf.config.list_physical_devices('GPU'))
⚙
Add packages to an env
docker exec -it ai-lab bash # inside container: conda run -n torch-env pip install lightning mamba install -n tf-env -c conda-forge xgboost
