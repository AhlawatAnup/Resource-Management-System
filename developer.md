# Developer Guide

## 📘 Introduction

This guide is intended to help developers get started with the project, set up the development environment, and contribute effectively.

It provides step-by-step instructions for:

- Setting up the project locally
- Understanding the development workflow
- Creating and submitting pull requests (PRs)
- Following best practices to ensure smooth and quick merges

Whether you're a first-time contributor or an experienced developer, this guide will help you navigate the contribution process efficiently.

## 🔄 For Existing Developers

If you have previously developed or contributed to this project, please review the following updates and guidelines before committing new changes to your branch.

### ⚠️ Important Considerations

- **Code Formatting (Prettier)**
  - This project uses **Prettier** for consistent code formatting
  - Install Prettier in your local environment:
    ```bash
    npm install --save-dev prettier
    ```
  - Before committing any changes, run:
    ```bash
    npm run format
    ```
  - This ensures consistent formatting and helps avoid unnecessary diffs (extra spaces, indentation issues, etc.)

- **Stay Updated**
  - Always pull the latest changes from the main branch before starting work
  - Review any recent updates, refactors, or structural changes in the codebase

- **Merge Conflicts**
  - Resolve all merge conflicts locally before pushing your branch
  - Ensure your code integrates cleanly with the latest version of the project
